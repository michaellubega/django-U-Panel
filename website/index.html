Install steps

1. Choose platform Download Android or Windows, use the web app (including on iPhone and iPad until the iOS app launches), and use official university links only.
2. Install or open Android: open the APK and confirm install. Windows: run the installer, then open U-Panel from the Start menu. Web: sign in in your browser — no install needed.
3. Sign in Students use @studmc.kiu.ac.ug email. Staff use KIU-#### and the password from your administrator.
